# CodeAlpha_TaskAutomation
Python Task Automation Project for CodeAlpha Internship
CodeAlpha Task Automation

Project Description

This is a Python automation project developed as part of the CodeAlpha Python Programming Internship.

The project automatically moves image files from a source folder to a destination folder.

Technologies Used

- Python
- OS module
- Shutil module

Features

- Automatically creates a destination folder.
- Identifies JPG, JPEG and PNG image files.
- Moves image files into the destination folder.
- Displays successful completion messages.

How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Run the following command:

"py task_automation.py"
